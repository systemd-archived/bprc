# Bad Piggies Rovercraft Combination

BPRC is a mod of BPLE 2022.1.9 (based on Anstro Pleuton's [decompilation](https://github.com/anstropleuton/BPLE-2022.1.9) that mixes content from BPLE and Rovercraft 1, 2 and 3.

This mod also has some content from [BPSS](https://github.com/systemd-archived/bple-starry-sea), made by `Xinghai_Akane.`!

*(Project uses Unity Editor 2022.2.23f1c1, Editor 2022.2.23f1 will hopefully work)*
